Preview first. Materialize separately.

Campaign-plan preview cannot change the queue. Approval applies only the exact current manifest and does not start execution.

Derive a milestone plan

Replace M1 with the milestone ID from the approved roadmap.

ts: derive campaigns for milestone M1
Required state
An approved roadmap containing the milestone.
What it reads
The approved milestone, gates, dependencies, and queue state.
What it changes
Nothing; it previews a campaign manifest.
Approval required
No.
Success looks like
An exact dependency-aware plan and manifest token.

Approve the exact campaign plan

Replace <token> with the exact manifest token returned by derive.

ts: approve campaign plan <token>
What it reads
The unchanged manifest and current roadmap/queue state.
What it changes
Creates the planned campaigns in the queue.
Approval required
Yes; this command supplies exact-plan approval.
Success looks like
Campaigns exist but none has been started implicitly.
