Confirm state, then select ready work

Overview connects strategy and execution. Status validates the owner queue. Next safely runs one campaign by default or an explicit sequential batch.

Inspect whole-project state

ts: overview
ts: status
Required state
Campaigns have been created or bounded work has been added.
What it reads
Maps, roadmap, gates, focus areas, campaign state, and drift.
What it changes
Nothing.
Approval required
No.
Success looks like
The next ready campaign and any blocker are explicit.

Select the first ready campaign

ts: next
What it reads
A freshly validated owner queue.
What it changes
Starts the selected campaign and executes only that campaign.
Approval required
The request authorizes the selected campaign at its natural endpoint.
Success looks like
One ready campaign is working; blocked or ambiguous work is not guessed.
