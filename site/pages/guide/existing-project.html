An existing managed Tool Shed installation.
What it reads
Published release, local installation, Git, work, campaign, index, and reconciliation state.
What it changes
The upgrade changes the managed installation; version and doctor are read-only.
Approval required
The full-upgrade request is the authorization.

The latest verified published release and local skill agree exactly, and doctor gives one actionable workspace verdict.
