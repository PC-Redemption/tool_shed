Entry · new project

Start with intent, not paperwork

Install Tool Shed, preserve an evolving idea in one Idea Brief when needed, then carry its synthesis into PRM.

Step 1 of 3

Confirm the installed version

Required state
Tool Shed is installed in the project workspace.
What it reads
The local version manifest.
What it changes
Nothing.
Approval required
No.
Success looks like
A verified local version is reported.
ts: version

Step 2 of 3

Brainstorm the project idea

Replace <project idea> with the possibility or problem you want to explore. Use ts: discuss instead when you do not want durable capture.

ts: brainstorm <project idea>
What it reads
Your idea, matching Idea Briefs, and relevant workspace evidence.
What it changes
Creates or updates one tracked Idea Brief.
Approval required
The brainstorm request authorizes only that brief.
Success looks like
The current synthesis and useful exploration history survive the session.

Step 3 of 3

Carry the Idea Brief into PRM

ts: prm idea <idea-id-or-path>
Required state
The idea is coherent enough to pursue; visible unknowns may remain.
What it changes
Begins PRM from the brief and promotes it only after approved project-map direction captures it.
Approval required
Normal PRM project-map, roadmap, and campaign-plan boundaries remain separate.
Success looks like
Discovery has durable provenance and PRM owns the path to delivery.
