Step 2 of 6

Approve direction before execution

Develop is read-only, propose captures an exact revision, and approve establishes the strategic baseline. None of these commands creates campaigns.

Develop · read-only analysis

ts: develop roadmap
Required state
An established Project Map.
What it reads
Project evidence and existing strategic artifacts.
What it changes
Nothing.
Approval required
No.
Success looks like
Milestones, gates, decisions, and uncertainty are understood.

Propose · exact revision

ts: propose roadmap
What it changes
Records an exact proposal; creates no campaigns.
Approval required
No when planning autonomy covers a faithful proposal.
Success looks like
A proposal token protects the unchanged candidate and is handled internally.

Settle · strategic baseline

Covered faithful proposals advance automatically. The token command remains available for manual level-0 operation.

ts: approve roadmap <token>
What it reads
The exact unchanged proposal, current source state, and authority envelope.
What it changes
Settles the roadmap revision; still creates no campaigns.
Approval required
Only for a material direction choice or insufficient autonomy.
Success looks like
The strategic baseline is current without ceremonial token copying.
