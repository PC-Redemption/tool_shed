Approve direction before execution

Develop is read-only, propose captures an exact revision, and approve establishes the strategic baseline. None of these commands creates campaigns.

Develop · read-only analysis

ts: develop roadmap
Required state
An established Project Map.
What it reads
Project evidence and existing strategic artifacts.
What it changes
Nothing.
Approval required
No.
Success looks like
Milestones, gates, decisions, and uncertainty are understood.

Propose · exact revision

ts: propose roadmap
What it changes
Records an exact proposal; creates no campaigns.
Approval required
Not yet.
Success looks like
A proposal token identifies the unchanged candidate.

Approve · strategic baseline

Replace <token> with the exact proposal token returned by the preceding step.

ts: approve roadmap <token>
What it reads
The exact unchanged proposal and current source state.
What it changes
Approves the roadmap revision; still creates no campaigns.
Approval required
Yes; this command supplies it for the exact token.
Success looks like
The approved strategic baseline is current.
