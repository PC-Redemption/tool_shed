Observe

Hosted Tool Shed dashboard

See project, App Server, and Work Efficiency health across explicitly enrolled instances without giving the hosted service control of local work.

Local state stays authoritative

The dashboard is an advisory read model. It accepts only allowlisted counters, controlled event codes, sanitized failure groups, and explicit coverage metadata. It never receives prompts, source, paths, raw diagnostics, credentials, or secrets, and it cannot mutate local Tool Shed state.

Approve each instance

ts: dashboard connect https://ts.rookaro.com

The local reporter shows a short-lived approval code. A signed-in maintainer approves the matching request in the dashboard. Then complete enrollment:

ts: dashboard connect poll

The one-time reporter credential is stored privately outside the repository. Use ts: dashboard disconnect to revoke it.

Report reliably without blocking work

Managed writes enqueue an idempotent local event and wake one background worker. Delivery retries with bounded backoff, sends heartbeats while active, and sends a quiescent state after two idle hours. A project-scoped 15-minute user scheduler compares the local domain digest and converges any missed write.

ts: dashboard scheduler install

Hosted reporting failure never blocks the originating local write. Check local state with ts: dashboard status, and use ts: dashboard scheduler remove when disconnecting permanently.

Host behind HTTPS

The supported stack uses Django 5.2 LTS, PostgreSQL 17, Gunicorn, and Nginx. Deployment secrets come from protected environment state. Public routes are limited to documentation, health, enrollment request/poll, and credential-authenticated report ingestion; fleet views and enrollment decisions require the configured maintainer authentication mode.

Back up and recover deliberately

Take encrypted daily PostgreSQL backups, retain seven daily and four weekly copies, and test restore quarterly. The first release targets a recovery point of 24 hours and recovery time of two hours. Reporter credentials can be revoked and re-enrolled; local Tool Shed data remains intact during hosted recovery.
