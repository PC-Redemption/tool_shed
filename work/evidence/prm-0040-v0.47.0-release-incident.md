# PRM-0040 v0.47.0 Production Preflight Incident

Status: mitigated; v0.47.0 content rejected for production deployment
Recorded: 2026-09-05
Release campaign: CAMP-0164

## Incident

During the production staging preflight, the documented command
`scripts/build_docs_site.py --output <production-directory>` removed the existing output directory
before generating the public bundle. The production directory also contained protected deployment
configuration, encrypted backups, and rollback bundles, so those colocated entries were removed.
The running v0.46.0 containers and PostgreSQL volume remained healthy and were not restarted.

Protected environment and backup configuration were restored from the external
`ts.rookaro.com.backup-20260830T205657Z` snapshot. All recovered runtime configuration values were
compared to the live container environment without logging their values and matched. A fresh
encrypted database backup was then created and successfully restore-listed.

Encrypted backup files created after the external snapshot and the former release rollback bundle
were not recoverable from local storage. The current PostgreSQL volume was unaffected; no database
records were lost.

## Additional Backup Finding

The deployed backup script had independently been failing before this release attempt because
`age` can exit with SIGPIPE after `pg_restore --list` finishes reading a valid stream. Its
pipefail handling now accepts only that exact decrypt status when `pg_restore` succeeds. A fresh
validated encrypted backup proves the repaired path.

## Release Disposition

v0.47.0 remains a published immutable artifact but was not deployed to production. The replacement
content adds a builder guard for recognized deployment-owned state, tests preservation and normal
bundle replacement, and changes the deployment runbook to build into a fresh staging directory and
synchronize only generated artifacts. Production promotion resumes with v0.47.1 after exact-SHA CI
qualification.
