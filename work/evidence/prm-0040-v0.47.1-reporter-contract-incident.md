# PRM-0040 v0.47.1 Reporter Contract Incident

Status: reproduced; corrective release required
Recorded: 2026-09-05

After v0.47.1 passed production web and official client-upgrade checks, the canonical reporter's
closeout report was rejected with HTTP 400. The local closure audit emits the expected state
`retain-open-until-recursively-closed`, while the hosted schema-eight validator and database field
allowed only 32 characters. The reporter therefore could not refresh the production dashboard even
though its canonical state was valid.

The correction expands this existing shared field to 64 characters in validation and storage,
adds the required Django migration, proves the real recursive-closure value is accepted, and
retains rejection above the new bound. Production completion requires successful delivery of the
previously rejected canonical report after the corrective release.
